# 第三批：专业修图与绘画

本批新增局部修补、纹理填充、精细蒙版、边缘去色、液化、保边降噪、手动镜头校正，以及画笔动态。入口是高级操作区的「专业修图…」和画笔工具栏。

## 使用

先选择普通 RGB 像素图层；文字、形状、智能对象需要先栅格化。修补、内容感知、蒙版和去色还需要当前选区。精细蒙版仅读取图层缓存，可用于智能对象或像素锁定图层；写入蒙版仍遵守整层锁定。对话框提供原图、预览、应用、取消。预览不会创建历史；应用一次对应一次撤销，关闭对话框取消尚未提交的计算。文档在对话框打开后变化时拒绝应用。

- 修补：选区指定目标，同一图层的 X/Y 偏移指定取样源。融合为 0 时复制源纹理；融合为 1 时通过 48 次迭代的 Poisson 边界解融合色调，保留目标透明度。
- 内容感知：从选区外的原始可见像素寻找匹配小邻域，由边界向内部填充；不会把刚填入的像素用作源样本。确定性搜索，适合局部瑕疵和简单背景，不是生成式填充。
- 精细蒙版：引导滤波、对比度和偏移生成软边；可输出选区或图层蒙版。在预览拖动可限制细化区域，区域以外的选区保持原样。默认替换当前图层蒙版；不修改图层像素。
- 去色：从选区内部覆盖率 ≥95% 的像素取色，修正半透明边缘；保留图像 Alpha。
- 液化：向前推移、收缩、膨胀、旋转，预览中拖动后松开查看结果。选择区域外冻结。单次最多 256 个点；重置清除未应用笔触。
- 降噪：双边空间／颜色权重平滑，支持半径 1–5 和强度 1–100，保留 Alpha。
- 镜头校正：径向 k1/k2、缩放、中心位置和暗角补偿；超出原图层边界为透明。没有自动镜头数据库。

预览显示当前选区或画布中心最多 512×512 像素。降噪、液化和镜头的预览仅计算该窗口；应用才处理完整作用范围。最终结果继续由现有 Haiyue 显示管线呈现；修图计算是可取消的 CPU 区域运算，并非 GPU Compute。

## 画笔

`image.pixels.stroke` 的既有参数之外增加：

| 参数 | 范围／含义 |
|---|---|
| flow | 0.01–1，每个笔尖的流量，累积不超过笔画 opacity |
| spacing | 0.02–2，笔尖间距相对画笔大小；最低 0.5 px |
| roundness / angle | 0.05–1 / −180–180°，椭圆笔尖 |
| scatter | 0–1，确定性位置散布 |
| texture | 0–1，固定画布坐标的颗粒强度 |
| smoothing | 0–0.95，输入坐标低通平滑，有跟随滞后 |
| tip | `{width,height,data}`，1–64 像素灰度笔尖，data 为 0–255 数组 |

未设置任何扩展参数时保留原连续笔画行为。扩展笔画按行程固定间距布置笔尖，不因直线分成更多 Pointer 事件而加深；散布在普通／分块路径中一致。覆盖计算同时供橡皮擦、蒙版和原生 CMYK 画笔使用。现有笔压大小／透明度仍有效。

界面有圆笔、喷笔、扁平书写、颗粒散布预设，允许导入不超过 4 MiB 的 PNG/JPEG 作为 64×64 灰度笔尖（深色为笔尖，白色／透明为背景）。「保存笔刷」保存一份本地「我的笔刷」，跨刷新使用。笔刷设置属于本地工具偏好，生成的像素属于文档。

本批没有实现 ABR 解析、笔倾斜、笔尖旋转动态、多预设库管理或可编辑的笔画对象。

## 命令与数据契约

新增 7 个 document write 命令，运行时共 111 个 Image 命令，统一由 Platform 暴露给进程内 API、IPC 和本地 RPC。所有命令必填 `layerId`，写操作沿用 `expectedRevision` 与取消信号，返回 `{applied:true}`。

| 命令 | 参数 |
|---|---|
| image.retouch.patch | dx/dy 整数 ±30000；blend 默认 1，0–1 |
| image.retouch.content-aware | search 默认 64，整数 4–128 |
| image.selection.fine | radius 1–32、contrast 0–100、shift 整数 ±32、edgeAware；output 为 selection（API 默认）或 mask；可选 region `{x,y,width,height}` |
| image.retouch.decontaminate | radius 整数 1–16、amount 0–1 |
| image.retouch.liquify | dabs 数组，每项 x/y、dx/dy ±512、radius 1–512、strength 0–1、mode 为 push/pinch/bloat/twirl |
| image.retouch.denoise | radius 整数 1–5、strength 1–100 |
| image.retouch.lens | k1/k2 ±1、scale 0.25–4、vignette ±1、centerX/centerY 0–1 |

修图支持 RGB8/16/32，包括浮点 HDR；RGB16 输出裁切到合法范围。CMYK 文档使用像素修图命令时明确要求先转换 RGB，不偷偷替换原生油墨。选区覆盖与透明像素锁在最终写入时应用一次。

输出复用不可变 256px 磁盘页、撤销、便携工程、自动恢复及 PSD/PSB 像素和原生蒙版。没有新增工程格式版本。PSD 保存的是编辑后的像素／蒙版，不会创建 Photoshop 可重新调参的液化或镜头智能滤镜。

## 工作集与边界

- 修补和去色的选区包围盒上限 262,144 px；内容感知为 65,536 px；细化含边缘扩展上限 2,097,152 px。超限时提示缩小选区或局部处理。
- 降噪和重采样按输出分块取原始邻域，不密集展开整图。重采样每块最多读取 64 个源块；过强的叠加形变超限时要求分次应用。
- 外部取样不可用、图层锁定、取消、参数错误和修订冲突不会提交半成品。
- 发丝提取目前是图像引导软边和局部去色，没有主体识别、毛发语义模型或完整背景颜色解混。
- 液化是栅格结果，已有蒙版保持原位；不支持冻结蒙版专用通道、面部识别液化、非破坏性形变网格保存。
- 本批没有 Photoshop 实机认证；算法不声称与 Photoshop 逐像素相同。

## 验收

`retouch-batch.test.mjs` 覆盖纹理填充、Poisson 融合、HDR 降噪、关联 Alpha 重采样、液化与冻结选区、局部细化、去色、笔尖／流量／散布一致性、跨 8192 分块与 COW、命令失败原子性、撤销和 PSD／工程／恢复。

`retouch-batch-browser.mjs` 验证真实面板预览、液化拖动、应用与撤销、内容感知、蒙版、格式往返及刷新恢复。报告和截图位于忽略的 `artifacts/retouch-batch/`。

本批增加修图算法及界面后，产物 raw 预算从 4.5 MB 调整到 4.6 MB；gzip 预算仍为 1.5 MB，继续执行产物体积校验。

图像编辑器构建为 Rollup 单独指定 `--heap-mb 4096`，其他产品仍默认 2048 MiB。避免大包压缩在旧堆限制下长时间回收；运行时文档预算未改变。
