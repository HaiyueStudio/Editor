# 大图：分块导入、视口、编辑与导出

文档几何上限为每边 30,000 像素，独立于整图工作集、压缩文件大小和设备单纹理限制。超过 8192 边长或 16,777,216 像素时自动选择大图路径。普通尺寸文档保留现有编辑／GPU 合成路径。

## 已实现

- RGB8 PSD：Raw、RLE、ZIP、ZIP prediction 图层通道按最多 256 行解码，直接压缩写入 256×256 磁盘页。仅有合并像素的 PSD 也可通过 Raw／RLE 分块导入。
- PSD Worker 与 `image.document.open` 使用同一个异步导入入口。大图不再强制展开整张合并图。失败／取消不会把半成品磁盘索引替换到原位图。
- 非交错 RGB/RGBA8 PNG 流式解码、CRC 校验、行滤波还原和磁盘写入；嵌入 ICC 按块转换到 sRGB，支持 Gamma。独立自定义色度／cICP 的大图 PNG 暂需转换颜色描述。JPEG 使用浏览器原生解码器，再按小画布分块提取；原生解码器内部内存不属于编辑器可控缓存。
- Haiyue WebGPU 显示画布按视口和 DPR 分配，上限 4,194,304 个显示像素及设备纹理边长，超出时降低显示分辨率，原始像素不变。
- 每张显示瓦片为 256×256 内容加一圈相邻采样像素（最大纹理 258×258）。线性采样前预乘透明度，避免透明边缘和分块接缝。
- 完整显示合成使用现有区域参考合成器，保持现有混合／蒙版／ICC 语义；WebGPU 负责瓦片采样、定位与显示。这一批没有把所有图层效果重新实现为 GPU 合成着色器。
- 显示金字塔按 2 倍递减，使用透明度加权降采样。缓存包含有界内存 LRU 和磁盘瓦片索引，缩放选择 LOD、平移只请求可见区域。原始像素仍使用文档的原生存储。
- 三通道 PSD 有真实合并图时先给出快速整体预览，再原子提交清晰瓦片，避免看到逐块补图。快速预览不是可编辑像素。导航器始终显示完整文档。
- 无 WebGPU 时使用同一套瓦片和区域算法显示，不创建文档尺寸的 Canvas2D。

## 预算与边界

GPU 显示瓦片缓存上限 48 MiB，单帧计划最多使用其一半，留出平移复用空间。显示金字塔内存缓存每份 8 MiB，磁盘页／解码缓存沿用现有独立预算。这些数字不是整个浏览器进程的总内存上限。

整图像素请求仍受 16,777,216 像素和 128 MiB 工作集保护，超出时拒绝，不隐式创建数 GB TypedArray。PSD／PSB 文件输入上限仍为 128 MiB，PNG/JPEG 输入上限仍为 32 MiB。第三批增加了 PSB 格式，文档几何上限仍为每边 30,000 像素。

下文按批次记录实现。第三批将这些分块路径扩展到原生高位深与 CMYK，并增加区域滤镜、HDR 显示和格式输出。未迁移的整图操作仍受预算保护。

显示金字塔首次建立需要扫描图像，因此首次高质量显示随文档像素量增长。已有层级缓存之后的缩放和平移不会再次扫描整图。金字塔索引在当前显示会话内复用；恢复后会重新生成，原始磁盘像素仍可复用。

## 第二批：分块编辑与流式输出

RGB8 大图现已接通界面和命令的区域编辑：

- 画笔／橡皮擦（软边、压力、透明像素锁定）、填充、线性／径向渐变。256×256 磁盘块采用写时复制；修改成功后一次提交，取消／磁盘失败／版本冲突不会提交半笔。未触及块与撤销快照共享，前驱提示采用弱引用，避免阻止历史淘汰。
- 矩形、椭圆、套索、加减交选、反选、扩张／收缩／羽化使用扫描线；颜色范围和四连通魔术棒逐条带取样，再连接扫描线。复杂选区／蒙版的扫描线预算为 32 MiB，达到上限明确拒绝。界面覆盖画布最长边 2048，不再按文档面积分配。
- 图层／滤镜蒙版从选区创建、反相、绘制、密度、羽化，以及图层蒙版应用。覆盖率使用稀疏扫描线，羽化缓存按区域分配。大型 Raw／RLE 像素蒙版支持分块读取；超过密集预算的 ZIP 像素蒙版导入仍需后续异步原生解码。
- 取色、局部像素复制、裁剪和图层移动可在大图使用。剪贴板保持 16,777,216 像素上限；全图传输应使用导出流。
- 像素层缩放、旋转、翻转与自由变换：最近邻、双线性、双三次、Lanczos。重采样使用条带／行缓存，变换确认只记一个历史项。大图拖动先更新手柄，停顿后异步更新像素预览；Esc 取消，原生内容需先栅格化，图层蒙版需先应用。复杂效果与智能对象的超大尺寸变换不在这一批。
- 局部像素修改及撤销只失效受影响的显示瓦片及其上级 LOD；图层结构、颜色设置和几何变化仍重建相应预览。

### 导出与 API

- PNG：按 32 行合成、转换输出颜色、DEFLATE 编码，逐块写出，不创建整图 Canvas。输出为带可选 sRGB ICC 的 RGBA8。
- PSD：RGB8 分层通道 ZIP、蒙版 RLE、合并预览 RLE，通道先暂存磁盘再输出。保留原生元数据、分组、分项锁、路径坐标和已有资源；沿用既有栅格化确认策略。上限 2 GiB，未加入 PSB。
- 界面优先使用文件系统写入流；无直接保存接口时收集压缩输出为 Blob，回退上限 512 MiB。这种回退不是恒定内存。大图 JPEG 仍需要另行加入流式编码器。
- 原有 `image.document.export` 继续返回资源，输出仍受 128 MiB 资源预算限制。新增 `image.export.prepare` → `image.export.read` → `image.export.close`，适合 IPC／本地 RPC 分段读取：
  1. `prepare({format:'png'|'psd', embedProfile?, allowRasterize?})` 返回 `exportId, bytes, chunkBytes, expiresInSeconds`。
  2. `read({exportId, offset, length})`，`length ≤ 4194304`，返回二进制资源句柄、`nextOffset, done`。支持重试读取同一偏移；调用方读取后应释放资源。
  3. `close({exportId})` 释放导出目录。最多 4 个导出，空闲 30 分钟失效，工作区关闭后不可继续读取。

导出使用开始时的不可变文档快照。导入文件大小限制仍沿用第一批，导出流并未自动扩展文件输入预算。高位深／CMYK 大图的完整编辑、超大复杂滤镜和 PSB 属于后续批次。

## 第三批：原生精度、区域效果及格式扩展

- RGB16／RGB32 HDR、CMYK8／16 使用原生磁盘块进行画笔、橡皮擦、填充、渐变、取样、局部复制、蒙版应用和自由变换；撤销共享未修改块。RGB32 超白和负值保留；CMYK 通道工具直接编辑油墨，RGB 工具沿用 ICC 分色要求。
- 滤镜按请求区域和实际邻域读取源像素，包括高斯、USM、柔化、锐化、浮雕、马赛克及逐像素色彩滤镜。马赛克按原图层网格对齐。选区和透明锁在滤镜结果上混合，避免模糊被瓦片／选区边界截断。
- 智能滤镜堆栈逐级反推所需邻域，支持不透明度、混合和滤镜蒙版；局部笔画的显示失效范围包括滤镜支持半径。大图对话框使用有界金字塔预览。大图可转为智能对象并从原始磁盘源缩放／旋转；带蒙版的智能对象仍需先处理蒙版。
- 文档位深转换、HDR 曝光、RGB／CMYK 模式转换和 ICC 指定／转换按块执行，再一次提交历史。ICC 的原有参数化内容栅格化要求保持不变。
- 大图系统 HDR 使用 Haiyue WebGPU 设备、浮点显示金字塔、258×258 以内的 `rgba16float` 纹理和 `extended` 画布；GPU 瓦片仍受 48 MiB 预算，单纹理尺寸不再取决于文档尺寸。系统不报告 HDR、启用软打样／自定义显示器配置时使用 SDR 预览。物理屏幕亮度和 EDR 行为需要真机验收，模拟媒体特性测试不等同物理认证。
- RGB16／32、CMYK8／16 PSD 图层支持 Raw／RLE／ZIP／ZIP prediction 原生解码。以 32 行通道条带和单个输出块为工作集，分块落盘；高位深 ZIP 预测包含 16 位累计和 32 位字节重排。8 位超大 ZIP 蒙版转为覆盖率扫描线。
- PSD 原生分层通道和合并数据流式输出，保留 RGB 位深或 CMYK 油墨值。高位深使用 Lr16／Lr32 信息区。PSB 支持 64 位区段／通道长度、32 位 RLE 行表及附加信息宽长度；通过打开文件界面和导出格式选择进入。
- JPEG 增加 8 行条带编码（基线顺序 DCT、4:4:4、sRGB ICC、透明像素铺白），不依赖整图 Canvas。编码依据 [ITU-T T.81](https://www.w3.org/Graphics/JPEG/itu-t81.pdf)，使用本地实现；不是渐进式 JPEG。普通小图仍沿用浏览器编码器。
- `image.export.prepare` 的 `format` 扩展为 `png | jpeg | psd | psb`，JPEG 增加 `quality: 0.01–1`。`image.document.export` 同样支持这些格式，保留资源预算。流式文件保存支持 PSB 长区段，RPC 暂存总预算仍为 2 GiB；浏览器 Blob 回退仍为 512 MiB。

### 明确边界

输入文件预算和 30,000 像素几何上限没有解除。只有合并缓存、没有图层像素的高位深／CMYK 大图尚未走原生分块恢复；16／32 位蒙版仍保留浮点密集覆盖率，超过 16,777,216 像素／64 MiB 时明确拒绝，不降低蒙版精度。8 位复杂扫描线仍受 32 MiB 预算。智能滤镜的 PSD 原生描述映射仍沿用导出转换提示；`.hyimage` 保留可编辑堆栈。
