# 第二轮 P1：提前预览与增量交互

承接 [第二轮 P0](interaction-p0.md)，本批实现 PSD 解码前的只读预览、大图笔刷增量执行和交互式自由变换 GPU 预览。

## PSD 导入

- Worker 先读取头部、资源段和合并图采样行，跳过图层通道，发送独立 `preview` 消息；`workerTask` 不把中间消息当作任务完成。右下角任务面板显示只读缩略图，导入对话框和可编辑文档仍在完整解码、兼容性和字体检查结束后发布。
- 支持 PSD／PSB 的真实 Raw／RLE RGB 8／16／32 位、CMYK 8／16 位合并图，包括单一透明通道的去白色底色处理。RGB 预览最长边 512，CMYK 256；按嵌入 ICC 和现有 SDR 显示规则转换，不改原生数据。
- ZIP 合并图、额外专色通道、缺失或占位合并图目前没有提前缩略图，继续正常导入。可选预览损坏不阻止图层导入；取消终止 Worker，丢弃晚到消息，不新增文档或历史。

## 大图画笔

- RGB／CMYK 画笔与橡皮擦共用 `BrushPath`，只对新增输入生成一次连续线段／散布印章；笔压、平滑、间距和随机序列跨批次连续。UI 读取合并的指针事件。
- `TiledStrokeSession` 保存不可变原始像素以及每个已触及分块的覆盖率检查点。更新只处理新增线段穿过的 256×256 分块，覆盖率写入磁盘，不随笔画长度积累整图 RAM 工作集。重复触及的像素仍相对笔画开始时的原值计算，避免不透明度因预览次数累加。
- 未修改的磁盘页与历史共享；新的空白大图共享同尺寸透明页，已有页在对齐时直接复用。保留选区、原生位深、CMYK 分色、透明像素锁定和画布外原始像素。
- 输入更新合并到当前任务，预览过程中不会反复取消再重放。松开只处理未完成的输入并复用最后结果，单次提交、单次撤销；Esc、切换文档、外部版本变化和销毁均取消，不发布旧结果。
- 蒙版画笔、仿制和修复暂时继续使用原有精确笔画计算，但共用合并调度和提交结果复用。修复了仿制／修复预览错误使用普通前景色画笔的问题；这些工具尚未使用覆盖率增量检查点。画布与画布外图层合并后超过 30000 边长的情况也使用原局部计算路径，避免扩大存储边界。

## 自由变换

- 启动不再为校验而生成整层像素。准备一次最多 1024 边长的文档显示面和最多 512 边长的图层代理；优先使用解码时的预览缓存，无缓存则分块生成。代理只用于显示，不能进入历史、导出或原始像素缓存。
- Haiyue Engine 的 WebGPU 合成器对每个图层执行逆仿射采样，保留堆叠顺序、透明度、已支持的混合和 matrix/TRC ICC 显示转换。拖动仅改变矩阵，复用纹理，不生成磁盘变换结果。支持单层、普通智能对象、多层和受支持的穿透组；多层不会先合并为一个覆盖在顶部的贴图。
- Enter 才调用原有原始精度变换并提交一条历史；重复 Enter 不会重复计算，无变化确认也不计算；Esc 和外部修改取消，旧任务不能取消或覆盖后来启动的会话。
- GPU 快速预览采用现有合成能力准入：RGB8、最多 8 个可见像素层、九种混合、无启用蒙版／样式／滤镜／调整层等参考合成效果，ICC 为隐式 matrix/TRC 配置。单层网格智能对象、高位深、CMYK、显式 ICC 工作流和其他复杂合成继续保留精确提交；拖动只显示边框，并明确提示。快速预览是近似采样，确认后恢复原始精度显示。

## 验收

```sh
npm test -w ./imageEditor
npm run typecheck -w ./imageEditor
npm run build:app -w ./imageEditor
npm run check:boundaries
node imageEditor/test/interaction-p1-browser.mjs
node imageEditor/test/daily-browser.mjs
node imageEditor/test/tiled-native-browser.mjs
node imageEditor/test/import-p1-browser.mjs
node imageEditor/test/interaction-p0-browser.mjs
```

`interaction-p1.test.mjs` 对比一次性和分批笔画的每个样本，覆盖跨块、重复轨迹、RGB 8／16／32、CMYK 8／16、透明像素锁定、橡皮擦、空白大图、画布外像素、不可变快照、取消和撤销；还检查 PSD 读取范围／ICC／透明通道、中间 Worker 消息和变换逆矩阵。

浏览器测试使用 9001×1900 PSD，记录提前预览时间，验证完成前只读、取消不发布、GPU 连续拖动零纹理上传／零磁盘写入、一次确认、撤销和笔画增量计数。指标为本机输入到提交诊断，包含测试驱动轮询，不代表显示器最终呈现延迟。

全应用包体约增加 14 KiB（含 UI、Worker、GPU 和检查点代码）；整体 raw 预算由 4,600,000 B 调整为 4,650,000 B，gzip 预算保持 1,520,000 B。原生像素、GPU 瓦片、源纹理和磁盘工作集预算保持不变。最终构建与各套件结果见 `artifacts/interaction-p1/acceptance.json`。
