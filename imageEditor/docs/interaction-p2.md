# 第二轮 P2：扩大 GPU 合成与降低缓存开销

承接 [第二轮 P0](interaction-p0.md) 和 [P1](interaction-p1.md)，本批实现按瓦片分批合成、多层蒙版／剪贴组、局部参考合成、增量预览指纹和独立缓存访问记录。

## GPU 瓦片合成

- 取消常驻路径的“最多 8 层”限制，沿用文档层数上限。每个 256×256 瓦片只处理实际重叠的图层，每批最多 4 层。源纹理、蒙版和滤镜临时表面在提交后解除占用；跨批次的合成目标与剪贴组累积目标继续保留。原有 8 MiB 合成池、48 MiB 显示池、64 KiB 参数池保持不变。
- 普通图层蒙版支持偏移、外部默认值、密度、禁用、羽化、稀疏覆盖与磁盘浮点样本。覆盖率按局部区域计算和缓存，以两个 8 位分量保存精度，GPU 执行 Alpha 应用。羽化按 64×64 区域计算，避免为 GPU 上传分配整张羽化蒙版；这是 CPU 覆盖率准备与 GPU 应用的组合，并非全部蒙版计算均为 GPU 着色器。
- 剪贴层在底层独立的透明度范围内合成，再按底层的不透明度和混合模式加入文档。连续剪贴层可以跨批次；隐藏底层、孤立剪贴层、组内偏移和跨瓦片透明边缘遵守原参考合成语义。剪贴关系不会越过组边界。
- 五种逐像素智能滤镜继续在 GPU 执行。其他滤镜按现有区域滤镜逻辑准备图层源，随后接回 GPU 混合。对图层样式、Blend If、高级混合等，只有与影响边界及效果扩展范围相交的瓦片使用完整参考图层栈；实际应用通过现有可取消预览 Worker 处理这些瓦片，再上传到常驻金字塔，其他瓦片继续用 GPU 合成。
- 全局调整层、隔离组、带组蒙版／剪贴的组、非整数布局、CMYK、高位深、显式 ICC 和 HDR 仍采用原参考路径。隐式 matrix/TRC RGB 配置继续在 GPU 显示变换。此次不改变原生像素、历史、PSD 往返或导出算法，也不扩大 P1 的自由变换代理准入范围。
- 诊断增加 `referenceTiles`、`referenceSources`、`maskUploads`、`layerPasses` 和 `maxBatchLayers`，区分 GPU 与混合执行成本。

## 增量指纹与不可变结构共享

- 哈希按不可变缓冲的 backing／offset／length 缓存，只计算实际引用范围。结构指纹按图层和子节点复用；修改一层只重算该层及祖先，其他图层与像素哈希直接复用。名称、锁定、文档 ID 和历史版本继续不影响显示键。
- 文档提交保留已经冻结且由文档创建的未修改图层，嵌套更新仅替换变化的祖先路径；未改蒙版也保留身份。此项让真实 UI／API 提交能够使用增量指纹与 GPU 蒙版缓存，而不只是直接传递测试状态时复用。
- 实际内容仍参与哈希；新缓冲、参数、颜色工作流、图层顺序、撤销分支都会正确区分。换页可能在同一位图上替换存储形式，像素缓存清理世代会使结构备忘失效；异步哈希遇到世代变化重新计算。哈希不会触发超大位图的密集像素 getter。

## 持久缓存

- 缓存数据库升级为 schema 2：`tiles` 仅保存图像数据，`access` 保存访问时间与长度，`meta` 保存总量。读取用只读事务，命中只登记小型访问提示；相同键在 1 秒内合并，最多保留 1024 个提示、每批刷新 256 条，不重新读取或写入图像 payload。
- 写入及淘汰仍在一个跨存储事务中更新像素、访问记录与字节数，保持 64 MiB 上限。LRU 游标仅遍历小型元数据。刷新时间取较新值；已淘汰记录不会因迟到的访问提示复活。访问提示写入失败只影响淘汰顺序，不影响文档或渲染。
- 首次升级丢弃旧版可重建的预览数据；工程恢复、原生磁盘页与历史数据库不受影响。新指纹与 GPU 渲染键均升版，避免复用旧显示结果。

## 验收

```sh
npm test -w ./imageEditor
npm run typecheck -w ./imageEditor
npm run build:app -w ./imageEditor
npm run check:boundaries
node imageEditor/test/interaction-p2-browser.mjs
node imageEditor/test/render-p2-browser.mjs
node imageEditor/test/performance-p1-browser.mjs
node imageEditor/test/interaction-p0-browser.mjs
node imageEditor/test/interaction-p1-browser.mjs
node imageEditor/test/tiled-viewport-browser.mjs
```

`interaction-p2.test.mjs` 验证每瓦片准入／剪贴边界、局部回退、羽化覆盖率、缓冲范围哈希、真实文档的共享与嵌套更新、撤销和换页失效。

`interaction-p2-browser.mjs` 在本机 Chrome／Metal 上比较真实 GPU 输出与参考合成，包括 40 层、完整 256×256 分块、资源淘汰、蒙版参数、17 个连续剪贴层、普通及局部参考滤镜、复杂混合和磁盘浮点蒙版。还通过正式应用导入 24 层带蒙版／剪贴的 PSD，验证修改、撤销和导出；仅修改不透明度要求零源纹理上传。

缓存验收覆盖旧 schema 升级、连续只读命中、零 payload 重写、合并时间记录、竞争写入和 64 MiB 淘汰记账。原有渲染回归继续核对最终像素、ICC、设备恢复、后台取消、大图连续操作及持久恢复。完整结果与最终构建对应关系见 `artifacts/interaction-p2/acceptance.json`。
