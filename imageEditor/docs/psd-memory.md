# PSD 按需解码与分块存储

`sample.psd` 的约 23.99 MiB 是压缩文件大小；2500 × 3359、114 个图层／分组的图层缓存约需 161.98 MiB，另有 32.03 MiB 合并图。一次性解码约 194.02 MiB，因此此前超过 128 MiB 准入预算。

现在此文件可分层打开。没有提高文件、画布、图层数或缓存上限，也不会修改源文件。

## 按需解码

导入先读取几何和通道索引。对一次性解码超预算的 RGB8 PSD，尝试原始／RLE 通道的按需路径；不展开全部图层 RGBA。原件压缩字节由文档独占，图层通道和嵌入资源引用同一底层缓冲区。原合并图仍单独解码，供用户选择合并副本或预览。

- 渲染以 256 × 256 像素块读取可见图层；RLE 按行解码所需范围。
- 图层缩略图逐块缩放到小画布，避免缩略图触发整层展开。
- 解码块使用 16 MiB LRU；兼容现有全层工具的工作位图使用 64 MiB LRU。两个预算为每个 JS 执行环境独立的缓存预算，**不是浏览器进程总内存上限**。
- 画笔提交只压缩脏区域覆盖的块；未修改块继续引用原始通道。撤销／重做保留不可变块引用，重绘通过块身份确定损伤范围。
- 填充、滤镜、变换等现有全层算法在实际调用时仍会展开目标层。PNG 智能源第一次使用时也会完整解码该源，再进入工作缓存。导出编码器仍需要完整输出及临时工作缓冲区。
- Worker 结构化克隆只携带编码数据；跨线程后恢复非枚举像素访问器。返回缓冲区按唯一底层对象 transfer，避免共享源被重复复制。

RGB16／32、CMYK、ZIP 图层通道及其他未支持的分块语义继续使用原有准入和明确合并回退。没有真实合并图则不能回退。API 不会静默栅格化不支持的内容。

## 磁盘分块与工程文件

自动恢复使用 IndexedDB 中的 v14 清单及 SHA-256 寻址的 256 KiB 编码数据块。共享 PSD 缓冲区只存一次，编辑覆盖块独立存储；已存在块不重复写入。清单、新块与旧块回收在同一个事务提交，读取验证块长度和哈希。写入失败保留上一份有效事务并报告失败。

分块文档保存为 `.hyimage` v13，使用共享二进制缓冲区目录；像素不会为了序列化而展开。旧工程／恢复版本继续可读。

后续已实现真正的[通用异步磁盘换页](disk-paging.md)：压缩像素与原生档案可以退出内存，按需异步读回；恢复只读取清单，便携磁盘工程采用 v14。下文的 v13／98 块和 271 项测试记录为此前阶段验收；最新换页预算、API、验证与边界以上述文档为准。

## 此文件涉及的 PSD 特性

| 特性 | 当前处理 |
| --- | --- |
| 114 个图层／分组 | 保留树结构、名称、可见性、位置、不透明度与锁定状态的编辑 |
| 4 个穿透组 | 子层对已有背景合成；支持组不透明度。穿透组同时使用蒙版／样式／剪贴暂拒绝，需先关闭穿透 |
| 33 个文字层 | 保留字体名、点文本原点、行距和像素缓存；可编辑文字。未修改的原生文字描述原样复用 |
| 33 个嵌入 PNG 智能对象 | 保留嵌入文件、放置变换和恒等自定义网格；源按需解码，可用现有智能源／变换命令编辑 |
| 74 个颜色叠加、33 个内发光 | 支持颜色叠加与内发光的颜色、不透明度、大小、阻塞、噪点、范围、源和正常／滤色混合；UI 和 API 可编辑 |
| 停用效果描述 | 未修改该层样式时保留完整原生效果；修改样式后按当前启用能力重建 |
| `Txt2`、`lnkE`、`cinf`、图案预设 | 由原生档案及解析器保留全局文本、嵌入资源、合成信息；`Patt/Pat2/Pat3` 原始预设块补回输出。编辑文字后丢弃旧全局文本缓存，避免缓存覆盖新内容 |

PSD 导出为新的兼容副本。未修改层像素保持精确；原生参数保留不代表 Photoshop 渲染认证。内发光噪点／边缘采用本编辑器算法，合成图可能有细微差异；本机缺少原字体时，重新编辑文字会使用替代字形。此实现没有运行 Photoshop 实机认证，也没有声称支持任意变形、文字路径或全部 PSD 附加信息。

## API

已有 `image.document.open/query/export`、像素、文字、智能对象、样式与历史命令沿用原契约。

- `image.document.query.storage`：`mode`（`paged`／`dense`）、`sourcePsdBytes`、块与工作位图缓存计数／预算。
- 查询图层返回 `passThrough`；`image.layer.update.patch.passThrough` 可修改分组穿透。
- 文字内容可携带 `layout: {x,y,leading,width,height}`，用于保留 PSD 的点文本原点。
- `image.layer.styles.styles.innerGlow`：`color, opacity, size, choke, noise, source, blend, range`。
