# 高级选区与滤镜

本次扩展把 P2 的矩形范围升级为可带 8 位覆盖率的像素选区；P1–P3 的图层、保存恢复与 PSD 流程继续保留。

## 选区工具

左侧工具栏依次提供矩形、椭圆、自由套索、多边形套索、魔术棒和颜色范围。

- 自由套索：按住拖动描边，松开自动闭合；Esc 放弃当前手势，保留此前选区。
- 多边形套索：逐点点击，Enter 或双击闭合；Backspace 撤销最后一点，Esc 取消。
- 魔术棒：点击取样，默认选择四方向连通区域；取消“连续”可选择整个画布的相似颜色。
- 颜色范围：点击画布取样，或设置目标颜色后点击“按此颜色选择”，可覆盖互不相连的区域。
- 两种颜色选择均可配置 0–255 容差，并选择“当前图层”或“全部可见图层”取样。
  颜色距离使用预乘 RGB 与 alpha 的最大通道差；透明像素隐藏的 RGB 不参与选择。
- 工具选项支持新选区、相加、相减、交集；拖动/点击时 Shift 加选、Alt 减选、Shift+Alt 取交集。
- 顶部“选择”菜单提供全选、取消、反选、羽化、扩展、收缩、填充和清除。
  `Mod+Shift+I` 反选，`Mod+A` 全选，`Mod+D` 取消。调整半径为 1–64 px。
- 羽化采用可分离方框平均；扩展/收缩采用方形邻域，画布外按未选中处理。
  尚未实现磁性套索、边缘吸附、子像素抗锯齿、选择主体等功能。

橙色半透明覆盖显示复杂选区的实际形状，白色轮廓显示覆盖率达到 50% 的边界。
选区外的画笔、橡皮擦、填充、清除与滤镜保持像素不变；羽化边缘按覆盖率降低操作强度。
全选后反选会得到明确的空选区，不能退化为“不限制编辑”。对空选区裁剪会拒绝执行。
裁剪始终按选区外接矩形调整画布，不会自动删除非矩形选区以外的图层像素。

选区创建与修改现在进入撤销/重做历史，并标记工程为未保存；单纯切换选中图层仍不属于内容编辑。

## 滤镜

顶部“滤镜”打开当前像素图层的效果预览，可调参数、对比原图、取消或应用。

| 效果 | 参数 |
| --- | --- |
| 亮度、对比度、饱和度 | -100–100% |
| 色相旋转 | -180–180°，RGB 色相旋转矩阵 |
| 黑白、复古棕褐、反相 | 0–100% 强度 |
| 阈值 | 0–255 |
| 色调分离 | 2–32 级 |
| 柔化模糊 | 1–32 px，滑动方框模糊 |
| 锐化、浮雕 | 0–100% 强度 |
| 马赛克 | 2–64 px 色块 |

预览运行在独立 Worker 中，参数变化会终止旧任务，取消/关闭会释放 Worker；两分钟超时会报错。
应用之前不会改动文档，每次应用是一条历史记录。锁定图层和图层组不能直接应用滤镜。
模糊与马赛克按预乘颜色计算，避免透明隐藏色污染边缘；色彩类滤镜保持 alpha。
效果仅作用于当前图层，选区以文档坐标映射到嵌套组和偏移图层。

这是可撤销的像素处理，不是非破坏性调整层或 PSD 智能滤镜。
颜色运算仍沿用编码 RGB，未增加 ICC 色彩转换；P3 的 PSD 兼容边界保持不变。

## 工程与恢复

- 有蒙版的选区保存为 `.hyimage` version 2，蒙版采用严格校验的 base64，每像素 1 字节。
- 无蒙版时继续写 version 1；读取同时支持 version 1 和 version 2。
- 原有 version 1 工程可继续编辑；旧版编辑器会明确拒绝 version 2，避免把复杂选区错误地当作矩形。
- IndexedDB 自动恢复包含完整选区、软边缘和滤镜后的图层像素。
- PNG/JPEG/PSD 导出包含应用后的像素；选区仅属于工程编辑状态，不写入 PSD Alpha 通道。
- 文档尺寸/像素/图层预算保持不变，额外蒙版受画布像素上限约束，历史计入蒙版内存。

75 项产品单元测试通过，包含 13 个新增领域用例：选区反向、空选区、组合、曲线/凹多边形、
连续颜色与透明度、软蒙版绘制、选区调整、历史及格式校验、13 种滤镜、透明边缘和 PSD 像素往返。

滤镜预览/原图/取消/撤销、任务取消重试、工程下载和恢复、离线 Worker、跨图层取样。

## 选区回退修复

修复了属性输入尚未失焦时直接拖选的时序：先把焦点移到画布，提交名称、坐标或不透明度的输入，
再记录手势的文档快照，避免把这次属性提交误判为外部修改而取消新选区。
无内容变化的工作区刷新不再把旧选区画到当前拖选预览上。鼠标/触控取消事件仅取消所属手势；
子元素的隐式捕获释放、其他指针以及已经完成的捕获释放不会清掉当前选区。

新增 9 组选区手势浏览器回归，覆盖 12 次矩形/椭圆连续替换、属性失焦、实际像素编辑、
拖动中的工作区刷新、触控多边形、818px 窗口缩放下连续 8 次拖选，以及工程文件中的最终选区。
回归中发现并修复了滤镜对话框快速重开时被上一次延迟 close 事件清理的问题；新增同一事件轮次关闭/重开的用例。
证据另存于 `evidence/selection-gesture/`，不覆盖上一阶段快照。

```sh

```
