## 修复内容

- `effectsOpen` 是 PSD 保存的图层效果面板展开状态，原来被密集像素导入路径当作未知图层能力阻塞。现在保留其原生状态；该文件没有需要新增渲染的图层效果。
- `LMsk` 保存蒙版叠加显示颜色与透明度，本文件为红色、50/255。现在保留并在导出时校验，不将其应用为图像透明度。
- 含上述显示元数据或图案预设的密集像素文档使用原生档案保留描述符。16／32 位像素继续按原位深读写；导出自检根据位深和颜色模式选择解码器。
- `Pat2` 图案预设按原字节保留。图层 ID、标签和参考点随原生描述符保留；这不等于新增图案预设编辑界面。
- 原生档案使用独立 Uint8Array，避免调用方修改 Node Buffer 时改变源记录。工程保存、自动恢复和磁盘换页共用既有档案序列化。
