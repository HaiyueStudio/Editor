# P2：基础图像编辑工具

P2 完成可实际修改像素的编辑工作流，建立在 P1 的文档、历史和恢复机制之上。
正式 PSD 编辑导入/导出仍属于 P3，P0 的兼容性风险和 Photoshop 待验收项保持不变。

## 工具与操作

| 工具 | 操作与行为 |
| --- | --- |
| 画笔 B | 圆形硬边笔刷，1–512 px，前景色与 1–100% 不透明度；连续插值、边缘覆盖率抗锯齿 |
| 橡皮擦 E | 使用相同笔刷尺寸及不透明度降低像素 alpha；保留隐藏 RGB |
| 矩形选区 M | 拖动建立选区，约束画笔、橡皮擦、填充和清除；Mod+A 全选，Mod+D 取消 |
| 填充与清除 | 选区工具的选项栏操作；无选区时作用于当前图层的画布范围；Delete/Backspace 有选区时清除像素 |
| 移动 V | 拖动当前图层或组；画布获得焦点后方向键移动 1 px，Shift+方向键移动 10 px |
| 裁剪 C | 拖动区域，Enter 或“应用裁剪”提交；改变画布尺寸，保留画布外图层像素；锁定图层时拒绝裁剪 |
| 变换 | 左侧变换按钮打开尺寸、顺时针角度、水平/垂直翻转对话框；围绕像素图层中心提交 |
| 文字 | 左侧 T 按钮添加多行文字，字号 6–512，使用前景色；明确提示提交后成为独立栅格图层 |
| 导出图片 | 顶部按钮导出 PNG 或 JPEG；PNG 保留透明度，JPEG 合成到白底并支持质量 10–100 |
| 手形 H | 拖动画布；在其他工具中也可按住空格或使用鼠标中键平移；滚轮缩放 |

一次完整笔画或拖动只提交一条历史。Esc、指针取消、丢失捕获、窗口失焦、切换工具/文档
都会取消未完成的预览。Esc 没有待提交操作时取消选区。输入框与对话框保留原生快捷键行为。
图层面板的垃圾桶始终删除图层，不受选区影响。

## 文档与像素保证

- 绘图使用独立工作缓冲区，实时预览不修改文档像素。松开指针后由 `ImageDocument`
  进行锁定、版本与预算校验，复制像素所有权，再提交共享 History Service。
- 笔画覆盖率在同一笔画内取最大值，避免低不透明度随指针事件密度不断加深。
- 绘图与填充以文档坐标解释选区，正确换算父级组偏移；图层原有画布外像素不会被丢弃。
- 组合成先累积组坐标，在最终画布范围内隔离合成，支持负坐标子层和裁剪后的组。
  在移动过的组中导入图片或添加文字仍居中于画布。
- 选区是视图/编辑上下文，单独修改选区不产生撤销命令或未保存标记；像素命令的快照
  包含选区，裁剪撤销可恢复原选区。工程与自动恢复保存当前选区。
- `.hyimage` 版本仍为 1，新增可选 `selection` 字段，旧 P1 工程可打开；坏选区会被校验拒绝。
- PNG/JPEG 是合并画面导出，不清除工程未保存标记；可编辑图层仍保存在 `.hyimage` 中。

## 当前边界

本阶段为基础栅格编辑：不包含笔压、软笔刷预设、套索/魔棒/羽化、选区布尔运算、
透视变换、可编辑文字对象或滤镜。变换使用确定性的最近邻重采样，任意角度可见像素锯齿；
可通过撤销回退。文字字体由本机提供，提交后保存像素而非字体依赖。

P1 的尺寸、图层与内存预算继续生效。像素绘制、变换和工程序列化目前运行在主线程，
不作大图性能承诺；Worker、分块缓存、压力测试与原生安装包验收仍是后续工作。
