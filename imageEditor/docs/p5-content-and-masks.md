# P5：可编辑内容、蒙版与调整

P5 在现有选区、13 种像素滤镜和 PSD 工作流上加入可编辑文字／形状、图层蒙版、非破坏性调整，以及更多混合模式。工程格式与恢复记录保存参数和渲染像素；PSD 使用下面的兼容边界。

## 操作

- **文字**：工具栏 T 新建；内容面板“编辑内容”重新修改。支持多行、字号、三类字体、粗体、斜体、对齐和颜色。保存工程同时保留参数和像素缓存。本机字体可能不同，重新编辑时的字形可能变化；未编辑前使用原缓存。
- **形状**：顶部“形状”创建矩形、圆角矩形、椭圆或直线；可编辑宽高、圆角、填充、描边颜色／宽度。直线最小描边 1 px。通过移动工具或图层位置属性调整位置。
- **蒙版**：“从选区添加蒙版”使用当前软选区；没有选区时显示整个画布范围。点“绘制蒙版”后，黑色隐藏、白色显示、灰色半透明，画笔不透明度和当前选区参与编辑；橡皮擦在蒙版上涂黑。支持反相、停用、移除，以及将启用蒙版应用到像素层。文字／形状需先栅格化才能应用蒙版或执行像素变换。组、调整层支持蒙版，但不能直接应用到单张像素。
- **调整图层**：顶部“调整”创建亮度、对比度、饱和度、色相、黑白、反相。作用于同一隔离组内下方已合成的可见图层；可重新编辑参数，调整不透明度、顺序、显隐与蒙版。不会修改下方源像素。
- **混合模式**：正常、正片叠底、滤色、叠加、变暗、变亮、强光、差值、排除，共 9 种。调整层使用正常模式。
- 新建文字、形状和调整层位于根图层栈顶部。可编辑内容暂不直接接受画笔／像素滤镜／旋转变形；“栅格化图层”明确转换为像素，操作可撤销。所有内容／蒙版编辑都计入历史和恢复。

## PSD 兼容矩阵（P5）

| 能力 | .hyimage／恢复 | PSD 导入 | PSD 导出 |
| --- | --- | --- | --- |
| RGB 8 位像素、隔离组、位置、显隐、不透明度、锁定 | 保留 | 受现有准入检查约束 | 保留，逐层自检 |
| 上述 9 种混合模式 | 保留 | 支持 | 原生模式，独立重新合成验证 |
| 简单灰度像素蒙版、位置、默认范围颜色、启停 | 保留 | 支持有像素且无额外语义的蒙版 | 原生 PSD 蒙版，像素／坐标／启停自检 |
| 蒙版密度、羽化、矢量派生、真实蒙版等复杂语义 | 不支持 | 分层导入拒绝；有效原合成图可显式回退 | 不生成 |
| 本编辑器文字／形状 | 参数与像素缓存均保留 | Photoshop 原生文字／矢量仍需显式合并回退 | 经确认后逐层栅格化，保留图层和蒙版 |
| 本编辑器调整图层 | 参数保留、非破坏编辑 | Photoshop 调整对象仍需显式合并回退 | 经确认后整个可见文档合并为一张像素层 |
| 13 种像素滤镜 | 保存处理后的像素，可撤销 | 普通像素语义 | 普通像素语义，不写智能滤镜 |
| ICC | 原始资源保留 | 不执行 ICC 色彩转换 | 兼容副本保留资源 |

导出有编辑性损失时，导出按钮在勾选同意前禁用；导出的栅格／合并副本不改变当前工程。应同时保存 `.hyimage`。不宣称完整 Photoshop 原生对象往返；Photoshop 实机、跨设备字体、CMYK／16 位仍未验收。

## 存储与合成

含新内容、图层蒙版或新混合模式的工程写 `.hyimage` version 3，其余沿用 version 1/2；读取兼容 1/2/3。新能力的 IndexedDB 分块恢复 manifest 使用 version 4，像素与蒙版块复用现有哈希去重；旧恢复 version 3 继续可读。蒙版及历史计入已有内存预算。

混合公式遵循 [W3C separable blending](https://www.w3.org/TR/compositing-1/#blendingseparable)。带蒙版／调整的文档采用 CPU 整帧合成；普通像素文档保留 Canvas 快路径和有界缓存。P4 普通像素性能证据不等同于复杂蒙版／调整场景性能保证。当前没有实时 GPU 合成、富文本、任意路径、剪贴蒙版或智能对象。

```sh
npm test -w ./imageEditor

npm run test:browser:p5 -w ./imageEditor
PSD_P5_PYTHON=/path/to/python-with-psd-tools npm run p5 -w ./imageEditor

```

P5 测试覆盖数据所有权、锁定／参数拒绝、蒙版画笔与应用、撤销、组隔离、调整不透明度、工程／恢复往返、9 种混合、原生 PSD 蒙版，以及强制导出损失确认。浏览器验证内容重编辑、真实像素、蒙版绘制、撤销、Worker PSD 下载、恢复后参数及显示。独立 psd-tools 用 9 个混合＋四级灰度蒙版样本验证原层 RGBA、缓存和强制重新合成；缓存关联色误差 ≤ 1/255，独立合成关联色和 alpha 误差 ≤ 2/255。
