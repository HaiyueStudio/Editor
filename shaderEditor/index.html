从代码到画面

每个 Pass 编写 fn mainImage(fragCoord: vec2f) -> vec4f。像素坐标原点在左下角，输出 RGBA 颜色。

布局：拖动区域之间的分割线，调整预览、纹理、代码和编译输出大小。分割线也支持方向键；布局会自动记住。

运行：Ctrl / ⌘ + Enter 编译全部已启用 Pass。语法错误会显示行号，并保留上次成功的预览。代码编辑支持撤销、搜索和自动补全。

多通道：每个 Pass 最多四个纹理。选择 Buffer 自动启用它，并显示带 A/B/C/D 标识的实时画面预览；上传 PNG、JPEG 或 WebP 后可在所有通道复用。每张图片上限 8 MB / 4096 像素。点击「上传立方体贴图」选择 +X、−X、+Y、−Y、+Z、−Z 六张同尺寸正方形图片；保存时包含全部六个面。

内置素材：通道菜单包含 Noise、Blue Noise、MSDF 图集、未来城市和 WebGPU 图片。上传 MP4 / WebM 视频（24 MB / 4096 像素以内，编码由浏览器支持）后静音循环播放，随预览暂停、重置；保存和导出包含视频。

键盘纹理：选择「键盘」后点击预览画布。纹理尺寸为 256 × 3，左下角起第 0 行为按住状态，第 1 行为本帧按下，第 2 行为每次按下翻转的状态，R 通道为 0 或 1。A–Z 使用编码 65–90；采样中心为 vec2f((key + 0.5) / 256.0, (row + 0.5) / 3.0)。离开画布会释放按键。

反馈：执行顺序为 Buffer A → B → C → D → Image。已执行的 Buffer 读取当前帧；自身和后续 Buffer 读取上一帧。编译、重置或分辨率变化会清空历史。禁用 Buffer 会清空引用它的通道。

3D：Image 输出作为 Haiyue BasicMaterial 纹理，支持球体、立方体和圆环。鼠标拖动旋转，滚轮缩放，右键平移。暂停 Shader 后仍可调整相机。

保存：点击「保存作品」或按 Ctrl / ⌘ + S，将作品与上传图片保存到此浏览器。返回首页不会自动保存。导出 .hyshader 工程可跨设备备份。PNG 导出为 Image Pass 结果。Gallery 预览图来自真实 Shader 输出。

GLSL 导入：手动粘贴单个 Pass；支持标量/向量/矩阵、常用函数、条件、循环和 2D / Cubemap 纹理采样。多 Pass 和纹理需逐一配置。支持 #define 宏、续行、#undef、逗号分隔的多变量声明、整数/浮点前后置增减、可读写的标量/向量/矩阵全局变量、按参数类型匹配的函数重载及函数原型。支持只读 gl_FragCoord，像素坐标与 mainImage 参数一致，可用于 Buffer、Image 和辅助函数。支持嵌套三元表达式 condition ? a : b，仅执行选中分支，并保留自增、函数调用和参数回写。辅助函数支持 out/inout，可传入可写变量、向量分量及矩阵元素，并在返回时回写。支持 sampler2D / samplerCube 函数参数、iChannel0–3 的 uniform 声明，以及 texture、texture2D、textureCube、textureLod、textureSize、texelFetch。支持 mat2/mat3/mat4 和非方阵的构造、乘法、索引，以及 transpose、determinant、inverse、matrixCompMult 和 outerProduct。全局变量按像素独立初始化，可使用内置量与辅助函数计算初值。支持 #if 条件编译和具名结构体；暂不支持 include、宏标记拼接、数组声明。Cubemap 采样传入 vec3 方向，需在通道中绑定六面图片。

API / IPC：window.haiyueEditor.listOperations() 查看操作；window.haiyueEditor.execute(request) 调用。Electron 使用共享的本地 JSON-RPC 协议，详见项目 README。
